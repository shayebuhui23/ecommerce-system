## 四、库存与并发设计说明

- 扣减使用 `UPDATE products SET stock = stock - ? WHERE id = ? AND stock >= ?`，由数据库保证原子性，影响行数为 0 即视为库存不足，避免"先查后改"造成的超卖。
- 订单创建、明细写入、库存扣减、购物车清理在同一事务内，任一步失败整体回滚。
- 取消订单使用"订单 ID + 待付款状态"条件更新，只有第一次能成功，从而避免重复恢复库存。
