# 阶段二 功能测试用例：商品、分类与收货地址

- 测试环境：Windows 11 + JDK 11 + MySQL 8.0.44 + Chrome
- 测试数据：`src/database/seed.sql` 中的 8 个演示商品（1 个下架、1 个缺货）、4 个顶级分类、4 个 SKU
- 执行日期：2026-10-17

## 一、商品分类

| 编号 | 用例名称 | 操作步骤 | 预期结果 | 实际结果 |
| ---- | -------- | -------- | -------- | -------- |
| TC-P2-01 | 查询分类树 | 以任意角色 GET `/api/category/tree` | 返回 4 个顶级分类，children 字段存在 | 通过 |
| TC-P2-02 | 新增顶级分类 | staff 登录，POST `/api/category`，name=Temporary Category | code=200，分类树中可查到该分类 | 通过 |
| TC-P2-03 | 同级分类重名 | 再次提交同名分类 | HTTP 400，提示「同级下已存在同名分类」 | 通过 |
| TC-P2-04 | 新增子分类 | 对顶级分类提交 parentId | 子分类挂在父分类 children 下 | 通过 |
| TC-P2-05 | 禁止三级分类 | 将二级分类的 id 作为 parentId | HTTP 400，提示最多支持两级分类 | 通过 |
| TC-P2-06 | 删除有商品的分类 | staff 删除「消费电子」（下有商品） | HTTP 400，提示该分类下还有商品 | 通过 |
| TC-P2-07 | 删除空分类 | 删除 TC-P2-02 创建的空分类 | code=200，分类树恢复 4 个顶级分类 | 通过 |
| TC-P2-08 | 客户维护分类 | customer 登录，POST `/api/category` | HTTP 403 | 通过 |
| TC-P2-09 | 禁用分类不可用于商品 | 分类 status=0 时新增该分类下的商品 | HTTP 400，提示分类已停用 | 通过 |

| TC-P2-14 | 分类筛选含子分类 | categoryId 为顶级分类 | 返回该分类及其子分类下的商品 | 通过 |

| TC-P2-16 | 客户查看下架商品详情 | GET 下架商品 id=6 | HTTP 400/404，提示商品已下架 | 通过 |

| TC-P2-23 | 删除商品 | staff 删除测试商品 | 商品从列表消失（逻辑删除，数据库记录保留） | 通过 |
