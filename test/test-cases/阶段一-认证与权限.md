# 阶段一 功能测试用例：认证与权限

- 测试环境：Windows 11 + JDK 11 + MySQL 8.0.44 + Chrome
- 后端地址：`http://127.0.0.1:8080`，前端地址：`http://127.0.0.1:5173`
- 测试数据：`src/database/seed.sql` 中的 admin / staff / customer 三个账号（密码 123456）
- 执行日期：2026-10-17

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 | 实际结果 |
| ---- | -------- | -------- | -------- | -------- | -------- |
| TC-P1-01 | 管理员正确登录 | 已导入种子数据 | POST `/api/auth/login`，account=admin，password=123456 | 返回 code=200，data.userInfo.roleCode=ADMIN，data.token 非空 | 通过 |
| TC-P1-02 | 邮箱方式登录 | 同上 | account=customer@ecommerce.local，密码正确 | 登录成功，返回 CUSTOMER 角色 | 通过 |
| TC-P1-03 | 错误密码登录 | 同上 | account=admin，password=wrong | HTTP 400，提示「账号或密码错误」，不区分账号是否存在 | 通过 |
| TC-P1-04 | 用户名重复注册 | 已存在 admin | POST `/api/auth/register`，username=admin | HTTP 400，提示「该用户名已被注册」 | 通过 |
| TC-P1-05 | 邮箱重复注册 | 已存在 admin@ecommerce.local | POST `/api/auth/register`，使用相同邮箱 | HTTP 400，提示「该邮箱已被注册」 | 通过 |
| TC-P1-06 | 注册不能提权 | 无 | 注册请求体额外携带 roleId=1 | 角色字段被忽略，新账号角色固定为 CUSTOMER | 通过 |
| TC-P1-07 | 未登录访问受保护接口 | 未携带 token | GET `/api/user/me` | HTTP 401 | 通过 |
| TC-P1-08 | 普通客户访问管理员接口 | 以 customer 登录 | GET `/api/user/page` | HTTP 403 | 通过 |
| TC-P1-09 | 商家运营访问管理员接口 | 以 staff 登录 | GET `/api/user/page` | HTTP 403（仅 ADMIN 可用） | 通过 |
| TC-P1-10 | 管理员查询用户列表 | 以 admin 登录 | GET `/api/user/page?pageNum=1&pageSize=10` | 返回 3 条演示账号数据 | 通过 |
| TC-P1-11 | 管理员禁用普通客户 | 以 admin 登录 | PUT `/api/user/status`，userId=3，status=0 | 提示状态已更新，列表显示「已禁用」 | 通过 |
| TC-P1-12 | 被禁用账号继续操作 | 客户已被禁用且持有 token | GET `/api/user/me` | HTTP 401，提示账号被禁用，令牌被清除 | 通过 |
| TC-P1-13 | 管理员禁用自己 | 以 admin 登录 | PUT `/api/user/status`，userId=当前管理员 | HTTP 400，提示「不能禁用当前登录的管理员账号」 | 通过 |
| TC-P1-14 | 参数校验失败 | 无 | POST `/api/auth/register`，用户名长度 1 位 | HTTP 400，返回具体字段校验提示 | 通过 |
| TC-P1-15 | 前端未登录访问受保护路由 | 清除浏览器本地存储 | 直接访问 `/admin/users` | 跳转登录页并携带 redirect 参数 | 通过 |
| TC-P1-16 | 前端越权访问 | 以 customer 登录 | 地址栏输入 `/admin/users` | 跳转 `/403` 页面 | 通过 |
| TC-P1-17 | 退出登录 | 已登录 | 点击右上角头像 → 退出登录 → 确认 | 返回登录页，本地 token 被清除 | 通过 |
