## 四、状态一致性说明

- 支付成功、发货、确认收货均使用「订单 ID + 当前状态」条件更新，重复调用影响行数为 0 时直接返回业务错误，不会产生重复流水或重复状态变更。
- 模拟支付失败只写入失败流水，不修改订单状态，避免"支付失败却变成已付款"。
- 物流信息与订单一一对应，发货前校验是否已存在物流记录。
