## 七、已知限制

| 项 | 说明 |
| ---- | ---- |
| 支付 | 为模拟支付，不接入真实支付网关；失败分支仅用于演示 |
| 物流 | 物流状态为模拟值（运输中 / 已送达），不接真实物流接口 |
| 汇率 | 汇率由管理员手工维护，不接实时外汇行情 |
| 退款 | 首版为整单退款，未支持按商品部分退款 |
| 购物车 | 以商品为单位，同一商品的 SKU 选择在订单快照中体现，购物车未按 SKU 分行 |
| 部署 | 当前为本地单机部署，未提供容器化与生产环境配置 |
