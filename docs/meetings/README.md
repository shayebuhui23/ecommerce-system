# 会议记录

本目录用于存放课程要求的项目会议记录 / 阶段评审记录，作为「过程管理与团队协作」维度的支撑材料。

## 记录规范

- 文件命名：`YYYY-MM-DD-主题.md`
- 每次记录包含：时间、参与人、议题、结论、待办事项（含负责人与截止时间）
- 阶段完成后同步记录该阶段的实际交付、遗留问题与下一步计划
- 建议配合任务看板截图一起归档（截图放入报告 4.4 节）
